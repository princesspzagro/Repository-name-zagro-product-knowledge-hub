# ZAGRO Product Knowledge Hub

A responsive, interactive product-learning dashboard with product guides, illustrative imagery, category/species filters, FAQs, mode-of-action notes, and links to ZAGRO product references.

## Run locally
Open `index.html` in a modern browser. The dashboard is a static site and does not require a build step.

## Publish with GitHub Pages
1. Open **Settings** in this repository.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Important content notes
- Images in this prototype are illustrative animal/farm visuals, not official ZAGRO product-packaging photos.
- Product composition, registration, indications, dosage, compatibility, withdrawal periods, and claims must be checked against the current market-specific label and official documentation.
- Some portfolio guides intentionally avoid asserting an unverified mechanism where the exact formulation must first be confirmed.
- This is an independent learning prototype, not an official ZAGRO publication.

## Product reference links
The dashboard links to selected ZAGRO product pages and product-category pages. Availability and formulations may vary by market.
